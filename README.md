# فرص Flutter وAndroid في مصر

تقرير يومي ثابت لوظائف Flutter لمحمد Essam وAndroid Native لأسماء Atya.

## تشغيل محلي

```bash
npm install
npm run dev
```

## فحص الإنتاج

```bash
npm test
npm run lint
```

المشروع Next.js، وVercel ينشره تلقائيًا عند وصول push جديد إلى GitHub. ملف
`.github/workflows/ci.yml` يشغّل build وlint على كل push وpull request.
